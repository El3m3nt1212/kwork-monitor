# kwork-monitor

Монитор биржи заказов Kwork: по расписанию обходит ленту проектов, сохраняет каждое наблюдение в SQLite и присылает в Telegram только подходящие заказы.

Код написан Claude Code.

## Возможности

- **Обход всей ленты** (`/projects?c=all`) через Playwright с сохранённой сессией: полный проход не чаще раза в час, между ними лёгкий по первым страницам.
- **История в SQLite:** у каждого заказа в каждом прогоне — число предложений, процент найма покупателя, оставшееся время. По истории определяется, почему заказ исчез: истёк срок, исчез раньше (вероятный найм или отмена) или пропал вместе с пачкой других (событие площадки).
- **Оповещения в Telegram** по нишам — регулярные выражения в `alerts.py`. Заказы с большим числом предложений отсекаются, каждый заказ приходит один раз.
- **Отсев неподходящего:** лидогенерация («найдите нам клиентов»), накрутка и чужие аккаунты, проектирование под CAD, покупка готовых активов — список категорий в `classify.py`.
- **Пометка покупателя:** если монитор видел у него не меньше пяти завершившихся заказов и ни один не закрылся досрочно, оповещение приходит с этой пометкой.
- **Шортлист** (`shortlist.py`): открывает страницы лучших заказов, дочитывает полное описание и плашку «Низкая оплата», пишет `data/shortlist.md`.
- **Отчёт** (`analyze.py`): время жизни заказов и причины исчезновения, пишет `data/analysis_snapshot.txt`.
- **Защита от неполной выдачи:** пустая страница без текста «ничего не найдено» считается сбоем, страница перезапрашивается, а неполный прогон не помечает заказы исчезнувшими.

## Установка и запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
playwright install chromium
python login_setup.py      # войти в Kwork вручную и закрыть окно — сессия сохранится
python run_once.py         # один прогон; база появится в data/
```

```bash
python run_once.py --full       # принудительно полный обход
python run_once.py --keywords   # только по ключевым словам из config.KEYWORDS
python shortlist.py             # шортлист
python analyze.py               # отчёт
```

Для работы по расписанию — Планировщик заданий Windows: `pythonw.exe run_once.py` раз в 30 минут (`pythonw` — чтобы не всплывало окно консоли). `run_once.bat` — ручной запуск с выводом в консоль.

## Настройка

**Telegram.** Создать `.env` рядом с кодом:

```
KWORK_TG_TOKEN=токен_бота
KWORK_TG_CHAT=id_чата
```

**Что отслеживать:** ниши — `NICHES` в `alerts.py`, порог предложений — `MAX_OFFERS` там же; ключевые слова для режима `--keywords` — `KEYWORDS` в `config.py`.

**Обход:** паузы между страницами, число страниц лёгкого прохода, интервал полного — в `config.py`.

## Ограничения

- Между страницами ленты пауза 4 секунды: при более частых запросах Kwork начинает отдавать пустые страницы. Полный обход (~42 страницы) занимает несколько минут.
- Разбор привязан к разметке Kwork, проверенной в июле–августе 2026; если площадка её поменяет, `scraper.py` придётся поправить.
